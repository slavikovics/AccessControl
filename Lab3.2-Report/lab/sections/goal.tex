одной и той же задачи.

\textbf{Задание}:
\begin{enumerate}
  \item Создать методику оценки безопасности кода на основе результатов
  части 1.
  \item Сравнить по методике свою реализацию из части 1 с упрощённой.
  \item Оформить отчёт.
\end{enumerate}

\textbf{Постановка задачи.} Готового алгоритма для сравнения в задании
не было, поэтому для работы написана упрощённая реализация
\texttt{Lab3.2-NaiveVersion}. Она решает ту же задачу, что и раздел
«In-memory data» из части 1, но без мер защиты, которые были
использованы там.
