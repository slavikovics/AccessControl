\textbf{Цель:} получить практические навыки анализа журналов реального
удалённого сервера, доступного из сети Internet, и увидеть, какой фоновый
трафик получает любой публичный сервер.

\vspace{1em}

\textbf{Задание}:
\begin{enumerate}
  \item Установить на удалённом сервере веб-сервер и разместить на нём
  тестовую страницу, доступную из сети Internet.
  \item Настроить систему журналирования на веб-сервере.
  \item Выполнить анализ данных логов различных подсистем, в том числе
  SSH и веб-сервера удалённого сервера, за несколько дней.
  \item Оформить отчёт о проделанной работе.
\end{enumerate}

\textbf{Постановка задачи.} Используется реальный VPS (Ubuntu~24.04,
IP-адрес \texttt{212.192.9.89}) с доменным именем
\texttt{test-lab4.work.gd}. На нём установлен веб-сервер \texttt{Caddy} с
автоматическим сертификатом Let's Encrypt и тестовой страницей на React.
Сервер намеренно оставлен открытым: вход \texttt{root} и вход по паролю по
SSH включены, а администратор подключается по ключу через VPN
(\texttt{10.0.0.4}). Так в журналах накапливается настоящий интернет-трафик,
а не смоделированный.
