== Step 1: Install the MongoDB server package ==
[OK] Install mongodb-org
     $ sudo apt-get install -y mongodb-org
== Step 2: Create a persistent data directory ==
[OK] Create data directory
     $ sudo mkdir -p /var/lib/mongo_lab_data
== Step 3: Start MongoDB (bootstrap mode, no authentication yet) ==
[OK] Start mongod
     $ sudo mongod --fork --dbpath /var/lib/mongo_lab_data --port 27017 --logpath /var/log/mongo_lab.log --bind_ip_all
[OK] MongoDB accepted a connection and is ready
== Step 4: Create the administrator account through the localhost exception ==
[OK] Create admin user (role 'root' on 'admin')
     $ mongosh --port 27017 --quiet --eval db.getSiblingDB('admin').createUser({user:'admin',pwd:'AdminP@ss1',roles:[{role:'root',db:'admin'}]})
== Step 5: Restart MongoDB with authorization enforced ==
[OK] Stop the bootstrap mongod
     $ sudo mongod --shutdown --dbpath /var/lib/mongo_lab_data
[OK] Start mongod with --auth
     $ sudo mongod --fork --dbpath /var/lib/mongo_lab_data --port 27017 --logpath /var/log/mongo_lab.log --bind_ip_all --auth
[OK] MongoDB is back up with authorization enforced
== Step 6: Seed the application database with public and private data ==
[OK] Insert a document into public_notes
     $ mongosh --port 27017 -u admin -p AdminP@ss1 --authenticationDatabase admin --quiet --eval db.getSiblingDB('labdb').public_notes.insertOne({title:'public seed', visibility:'public'})
[OK] Insert a document into private_notes
     $ mongosh --port 27017 -u admin -p AdminP@ss1 --authenticationDatabase admin --quiet --eval db.getSiblingDB('labdb').private_notes.insertOne({title:'private seed', visibility:'private'})
== Step 7: Create 'labuser' - readWrite on 'labdb' only ==
[OK] Create user 'labuser' (role readWrite on labdb)
     $ mongosh --port 27017 -u admin -p AdminP@ss1 --authenticationDatabase admin --quiet --eval db.getSiblingDB('labdb').createUser({user:'labuser',pwd:'UserP@ss1',roles:[{role:'readWrite',db:'labdb'}]})
== Step 8: Create 'labguest' - read-only on 'labdb.public_notes' only ==
[OK] Create role 'guestReader' (find on labdb.public_notes only)
     $ mongosh --port 27017 -u admin -p AdminP@ss1 --authenticationDatabase admin --quiet --eval db.getSiblingDB('labdb').createRole({role:'guestReader',privileges:[{resource:{db:'labdb',collection:'public_notes'},actions:['find']}],roles:[]})
[OK] Create user 'labguest' (role guestReader)
     $ mongosh --port 27017 -u admin -p AdminP@ss1 --authenticationDatabase admin --quiet --eval db.getSiblingDB('labdb').createUser({user:'labguest',pwd:'GuestP@ss1',roles:[{role:'guestReader',db:'labdb'}]})
== Step 9: Start Mongo Express so the setup can be checked visually ==
[OK] Install Mongo Express
     $ sudo npm install -g mongo-express@1.0.0
[OK] Start Mongo Express
     $ mongo-express  &
[OK] Open http://localhost:8081 to browse 'labdb' (public_notes/private_notes) visually, connected as 'admin'
