# Lab3.2-NaiveVersion

Намеренно упрощённая версия хранилища из Lab 3.1 (данные в памяти, без БД),
написанная без учёта выводов Lab 3.1. Нужна только как база для сравнения
по методике из Lab 3.2.

Недостатки (заложены специально):

- нет валидации ввода, любая ошибка -> 500 с текстом исключения;
- нет ограничения размера запроса;
- "шифрование" -- XOR с ключом, записанным в коде;
- `activityLog` хранит открытый текст всех операций;
- обычный `Dictionary` и `id++` без синхронизации.

Запуск: `dotnet run` (http://localhost:5090/).
