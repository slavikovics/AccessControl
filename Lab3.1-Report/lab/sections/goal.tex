\textbf{Цель:} научиться анализировать безопасность кода приложения и
поведение конфиденциальных данных в оперативной памяти процесса.

\vspace{1em}

\textbf{Задание}:
\begin{enumerate}
  \item Разработать приложение с интерактивным интерфейсом, позволяющее
  создавать, обновлять и удалять в оперативной памяти конфиденциальные
  (зашифрованные) и неконфиденциальные данные.
  \item Выполнить анализ безопасности приложения с точки зрения кода.
  \item Выполнить анализ оперативной памяти и процессорного времени.
  \item Создать дамп памяти после ввода, обновления и удаления данных
  и проанализировать дампы.
  \item Оформить отчёт.
\end{enumerate}

\textbf{Постановка задачи.} Для выполнения работы приложение
\texttt{SecureApp} из лабораторной работы №2.1 дополнено разделом
«In-memory data». Его записи хранятся только в памяти backend-сервера и
не пишутся ни в базу данных, ни в файл.
